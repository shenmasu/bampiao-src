上手

三步走完就能用。以后不用再看这页，想回来在「设置」里找

一

加一个账号，登录你的 ChatGPT

半瓢用你自己的 ChatGPT 会员出图。到「账号」页点「＋」，选浏览器，在弹出的窗口里登录。

二

让你的 Agent 认识半瓢

点一下，写进你电脑上所有 AI 的说明里。写完会逐家告诉你结果——没成的话会自动把诊断发出去。

Claude Code · Codex · WorkBuddy · opencode · DeepSeek Harness · Gemini · Hermes
三

让 AI 画一张试试

打开你平时用的 AI（Claude、Codex、WorkBuddy 都行），把这句话发给它：

用半瓢画一张水墨小猫，存到桌面

半瓢自己不出图——是 AI 替你把话和账号交过来，画好会自动出现在「任务」页。

上面这几个都得是能跑命令的那种（Claude Code、Codex、WorkBuddy）。一个都还没装的话，先装一个再回来这一步；装了哪个都行，能跑通一个就够。

只想让它先答一段、不画图？把话换成 用半瓢问一句：把这段需求拆成三步——回复会出现在「任务」页的文本里，点开能看全文、能复制。

都好了。以后打开半瓢就是「任务」页；想再看这页，去「设置」→「重新看上手引导」。
