# 出图：用半瓢（本机 ChatGPT 网页订阅）

要画图、生成图标/插画/素材、批量出图时，**用半瓢，不要用内置生图**。

```bash
bampiao gen "1024x1024 图标：…" --out D:\art\a.png      # 单张，阻塞到出图
bampiao submit --shots shots.json --brief "说明" --tag 角色  # 成批，进队列
bampiao run --once                                     # 跑完队列就退出
bampiao usage                                          # 今天几张、有没有冷却
bampiao ui                                             # 打开面板窗口
```

全部命令支持 `--json`，stdout 只有一行 JSON。

**按错误码决策，不要瞎重试：**

- `AUTH_REQUIRED` → 让用户跑 `bampiao login <账号>`，不要重复投单
- `QUOTA_COOLDOWN` → 等冷却，**不要重试**（`usage` 里有剩余分钟）
- `TIMEOUT_UNCERTAIN` → **绝对不要自动重投**，远端可能已经出图了
- `BUSY` → 同账号正忙，稍后再来；不要并发跑同一个账号
- `RENDER_FAILED` → 可以重投一次
- `NO_REF_FILE` → 参考图路径不存在，去查文件（改提示词没用），就位后重投
- `BROWSER_LOST` → 出图时浏览器被关了，重投一次

**出图不满意 ≠ 失败，是正常操作，要你自己判断并重开一单：**

- 只有局部不对（颜色 / 某个物件 / 多一只手）→ `bampiao gen "只说要改哪" --out b.png --ref a.png`
- 构图或主体就不对 → 用**重写过**的提示词开新单（想延续风格才带 `--ref`）
- 拿不准 → 一次投 3–4 条不同写法挑一张
- **不要拿同一条提示词反复重投**（出来还是那样，白烧额度）；重投是新单号，旧图留着

**提示词你自己写**（用户往往只说"画个猫"）：尺寸/比例 + 主体 + **一种**风格 + 不要文字。
图标类加「粗轮廓、无渐变」；要透明底用 `--alpha`，不要自己在提示词里写"透明背景"。
改图必须 `--ref`，并说明只改哪一处。

**等待**：`gen` 会阻塞 1–3 分钟。能并行就丢后台、估两分钟回来收；只能顺序做就老实等，
返回后先看结果再决定。不要写轮询循环（没有进度接口），不要在循环里逐张 `gen`
（串行占同一个号），成批用 `submit` + `run --once`。

**连续两次同样的失败就停下问人**，别把额度耗在同一条路上。
交付前 `ls -l` 确认文件真的存在，别凭退出码 0 就说完成。

硬规矩：不碰日常浏览器 profile；不要开 Codex 的 `image_generation`
（那是故意的，开了就等于又回到吃 Codex 额度）。

另外，查资料、写方案、拆需求这类**文字活儿**也能交给它——同一份会员额度、同一批账号：

```bash
bampiao ask "把这个需求拆成三步，每步一句话"     # 结果直接打到 stdout
bampiao ask --file 需求.md --out 方案.md        # 读文件、写到文件
bampiao ask --json "..."                       # 只输出一行 JSON
```

- 它和出图共用账号池（会员额度），但**看不到图**——别让它判断画面好坏
- 默认 300 秒超时，长任务加 `--timeout 900`
- 我说「这段交给 codex」的时候，就是让你跑这条命令
